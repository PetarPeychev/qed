qed e2e demos

  • acceptanceAcceptance: the whole manual checklist in one recording, an assertion and a golden snap after every step.
  • edit-saveOpen a file, edit it, save it, check the bytes on disk.
  • filetreeWelcome screen on a directory, the file tree, Tab/Shift+Tab between its tabs, open a file from it.
  • findSyntax-highlighted Go file, incremental find, next match, close.
  • gotoGo to Line (Ctrl+G): fuzzy text query, a line number, :line:column, the live preview, Enter jumps.
  • lspclangd diagnostics, hover and completion on a C file (core-built popups at the caret).
  • markdown-imagesMarkdown preview: images sit in the flow like a browser lays them out: inline in text, in table cells, centered.
  • markdown-litehtmlMarkdown preview laid out like GitHub: cmark-gfm HTML on a terminal cell grid, rendered off the main thread.
  • markdown-splitMarkdown preview in a split: Toggle Split, live typing, two-way scroll sync, focus, links and history, plain buffers, width hot reload, the Alt+p overlay over the split.
  • markdownMarkdown preview pane.
  • mouseClick to place, drag to select, double-click a word, type over it.
  • palette-wrapSoft wrap on a long line, then the command palette turns it off.
  • searchProject search (Alt+F): rg results streamed into the list, a live preview of the hit, Enter opens it there.
  • settings-schemaTyped options in the settings menu: a disabled plugin, list items, map entries added through the language picker and removed with Ctrl+d (a default one through null), the theme picker, int bounds, a multi-line text option; then the Keybinds UI and a rebind in keybinds.json.
  • settingsSettings menu from the palette.
  • terminalEmbedded terminal pane running /bin/sh.
  • ui-dialogDialog plugin: qed.pick and qed.confirm on qed.ui (Settings: Indentation).
  • ui-editorqed.ui editor node parity: auto-pairs, move lines, find highlights through the shared view renderer.
  • ui-findFind plugin on qed.ui: query, regex toggle, replace one and all.
  • ui-layoutqed.ui layout plugin: editor node, status row and message line.
  • ui-logMessage log plugin on qed.ui: levels, selection, full text (timestamps vary, so only the closed state is a golden).
  • ui-paletteqed.ui command palette plugin: fuzzy list, scoped Next/Previous/Run, Esc, outside click.
  • ui-pluginsPlugin manager plugin: list, footer error, bundled source view.
  • ui-settingsSettings menu on qed.ui: filter, toggle a bool, number prompt, Tab/Shift+Tab tabs, chord capture, the open chord toggles.
  • ui-welcomeqed.ui welcome screen: the layout plugin mounts it in the background layer.
  • wheel-horizontalHorizontal wheel: with wrap off, Alt+wheel and the sideways wheel scroll the view left and right, from column 0 to the end of the longest line; the cursor stays put until it moves. With wrap on both are ignored.
  • workspaceOpen Directory (Ctrl+O): the path picker lists subdirectories, Tab and / drill, Backspace goes back, Enter switches.
